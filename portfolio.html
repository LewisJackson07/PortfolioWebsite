Nova Game

This was a project I completed for a University Assignment. I was tasked with creating a battleships like game in Java. I choose to make this as a terminal based application that when runs allows a user to play a game against another player on the same computer. It also has game state saving by saving to a file. I learned alot from this project but notably I improved by abilty to make terminal applications that are easy and robust to use.

Tetris

For my Advanced Higher Computing project I created a clone of the game Tetris. I made this using Python with the pygame library so I could make a GUI for it. I also used an SQL database that connects to the python game and it stores players details including usernames, passwords and highscores. This was my first time creating a project which I had planned out before going through a proper design approach with a design, implmentation and testing stages. For this I was awarded an A proving my approach and implmenation was very good.
